# Publication boundaries

AI Clinic Scribe Case Study is the public case study name used for a confidential client project.

This repository contains newly written, generalized documentation only. It is independent of the private implementation repository and does not share its Git history.

The following material is excluded:

- Client and clinic names, branding, logos, and identifiable screenshots.
- Application source code, database migrations, internal documents, and model prompts.
- Production URLs, infrastructure identifiers, credentials, and environment files.
- Patient recordings, transcripts, clinical notes, or any other patient information.
- Client commercial terms and unverified performance, accuracy, or compliance claims.

The case study makes no claim of HIPAA certification or clinical validation. Its scope is a general engineering narrative.
